Hero Items
----------
Emerald Resource
    - Obtainable by killing neutrals, selling items or selling resources
    - Used to buy resources now instead of direct exchange
    - Used to buy items from shops
    - Only shown if you have any
    - Neutrals now give emerald bounties
    - Update diplomacy menu resource exchange
    - Update all other commands related to resources
    - Resources class constructors should assume emeralds = 0

Hero Items
    - Hero inventory GUI
        - Click to use, can have charges and/or cooldown
        - Drag to move slots, drop on ground, transfer to another hero or sell
    - While held by a FPV player, can be right-clicked to give to a neutral unit and dropped on death
        - Should be visible to all players
    - Should have tooltips shown even on the ground
    - Requires right-click to pick up, will not auto-pickup


Balance
-------
[✔] Weakness and Strength now affect all unit auto-attacks, modifying it by 20% of base damage per level
[✔] Wither Skeletons now cause stacking weakness on hit
    - Regular units can have max 4 stacks of weakness, heroes can have 2
[✔] Wither Death Clouds add 1 stack of weakness
[✔] The Wretched Wraith can now produce snow on full-cube building blocks
    - This excludes things like stairs, bottom-slabs, plants and skulls


Quality of Life
---------------
[❌] Reduced starting capitol build speed by 33%
[✔] Improved hero particle effect visibility and added level up particles
[✔] Hero and higher value units are now prioritised for selection and attacks when mousing over dense groups
[✔] Workers rallied to a resource now auto-gather that resource even if the exact block is already mined
[✔] `/rtsapi-set-unit-enemy-search` now stops all current unit actions before applying the new search type
[✔] Workers ordered to hunt an animal when at max resources will first drop them off
[✔] Items that units pick up including resources and Piglin Merchant loot now have mouse-over tooltips
[✔] Neutral buildings with 1-9 blocks are no longer shown on the minimap
[✔] Neutral buildings with 11-49 blocks are now smaller on the minimap

Bugfixes
--------
[❌] Dropping an item in creative, then toggling RTS cam twice causes picked up items to not be shown clientside
[✔] Workers assigned to a farm can now always reach all food blocks on that farm
[✔] Big units no longer get stuck on transport portals when going through in big groups
[✔] Fixed having incorrect population values when switching between singleplayer maps
[✔] Fixed Wretched Wraiths taking damage from going underground with Frostblink
